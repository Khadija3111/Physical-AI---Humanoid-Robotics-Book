## 🚀 Overview

This repository contains my submission for **Hackathon I: Create an AI-Native Textbook for Teaching Physical AI & Humanoid Robotics**.

The project is a **fully published, AI-assisted technical textbook** combined with a **Retrieval-Augmented Generation (RAG) chatbot** that answers questions strictly from the book’s content.

The textbook focuses on modern robotics and embodied AI, covering **ROS 2, digital twins, simulation environments, VSLAM, and Vision-Language-Action (VLA) systems**, built using an AI-first workflow.

---

## 🧠 Project Workflow

This project follows a **hybrid AI + engineering workflow**, leveraging:

- **Spec-Kit Plus** — structured module specifications and consistency  
- **Gemini CLI (Google AI Studio)** — drafting, refinement, and validation  
- **Docusaurus v3** — documentation and publishing  
- **Vercel** — production deployment  

The result is a **production-ready, AI-native learning resource**, not static documentation.

## 🤖 2. RAG Chatbot Development — **COMPLETED**

A **fully functional RAG-powered chatbot** has been implemented to support interactive learning.

The chatbot:
- Answers queries **strictly from textbook content**
- Uses semantic search and embeddings
- Prevents hallucinations outside book scope
- Demonstrates agent-based reasoning

### 🛠️ Chatbot Architecture

- **Vector Database:** Qdrant  
- **Embeddings:** Cohere  
- **Agent Orchestration:** OpenAI Agents SDK  
- **Backend:** FastAPI  
- **Retrieval Strategy:** Book-content-only semantic search  

### ✅ Implemented Features
- Full textbook content embedded into Qdrant  
- Accurate semantic retrieval  
- Agent-based response handling  
- Context-aware answers aligned with textbook chapters  
- Clear separation of retrieval, reasoning, and response layers
