# Data Model for 004-agent-retrieval-api

This document outlines the key entities and their relationships for the retrieval-enabled agent.

## Entities

### Agent
*   **Description**: The core intelligence component, responsible for interpreting user queries, coordinating with Qdrant for retrieval, and formulating responses.
*   **Fields**:
    *   `id`: Unique identifier for the agent instance.
    *   `model_config`: Configuration for the underlying OpenAI model.
    *   `retrieval_strategy`: Defines how Qdrant is queried (global, selected-text).
*   **Relationships**: Interacts with FastAPI (receives queries, sends responses) and Qdrant (performs retrieval).

### Qdrant
*   **Description**: Vector database responsible for storing and retrieving vectorized book content.
*   **Fields**:
    *   `collection_name`: Name of the Qdrant collection storing embeddings.
    *   `host`: Qdrant service host.
    *   `port`: Qdrant service port.
*   **Relationships**: Provides retrieval results to the Agent.

### FastAPI Application
*   **Description**: Web service exposing API endpoints for interacting with the agent.
*   **Fields**: None specific to the data model, acts as an interface.
*   **Relationships**: Receives `User Query` from clients, invokes `Agent`, and returns `Agent Response`.

### User Query
*   **Description**: The input provided by the user to the agent.
*   **Fields**:
    *   `text`: The natural language question or prompt from the user.
    *   `context` (optional): Additional context, especially for "selected-text" mode (e.g., specific text snippet from the book).
*   **Validation Rules**: `text` is required, `context` is optional.

### Retrieval Result
*   **Description**: Information retrieved from Qdrant based on the user query.
*   **Fields**:
    *   `vector_ids`: Identifiers of the retrieved vectors.
    *   `payloads`: Associated metadata or content snippets for the retrieved vectors.
    *   `scores`: Similarity scores of the retrieved vectors.
*   **Relationships**: Generated by Qdrant, consumed by the Agent.

### Agent Response
*   **Description**: The final answer or output generated by the agent in response to a user query.
*   **Fields**:
    *   `answer`: The natural language answer.
    *   `sources` (optional): References to the retrieved content used to formulate the answer.
*   **Validation Rules**: `answer` is required.
